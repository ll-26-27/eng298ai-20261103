AI Humanities Lab: Claude Code & vibe coding

Describe what you want in plain language, have Claude build it with you, then inspect, test, and revise the result. These are the worked examples: books, translations, maps, and conversations, each one a finished page you can open.

Every example follows one familiar shape. Each folder in the repository holds its source material, the numbered steps that ran, and the page below.

Inputsthe books, articles, and records you start with
Operationsthe prompts, scripts, and checks you run on them
Outputsthe pages, maps, and essays you make for others

Outputs become new inputs: the timeline feeds the talking-machines map, and the pharmakon texts feed the Phaedrus walk.
