How Frankenstein travelled

The first translation of Mary Shelley's novel into each of languages, checked against library catalogues and published studies, and one passage, the creature's awakening, followed into the translations we can legally read.

Each row is a language; the dot is the year of its first translation of the novel. Filled dots are confirmed in a catalogue or a scholarly source; half-filled are confirmed in part; dashed rings are leads we could not confirm. Click a row or a city on the map for the record.

One passage, translated four ways

The opening of the creature's awakening (1818, vol. I, ch. IV), in the 1821 French translation and in translations made for this page by a model, each one-shot and after a critique by a second model. Every version is back-translated into English by a third pass and its departures from Shelley sorted into six categories. Hover a change to see it in both texts. The categories are an interpretive choice for teaching, not an established taxonomy.

Translate, critique, translate again

A chain instead of a one-shot: one model translates, a different model critiques, the first revises and says which criticisms it accepted.

What the models remembered

Before any research, two models were asked for the same inventory from memory, with no web access (step 1a). Here is what they said beside what the catalogues say. One model declined most rows; the other answered every row with confidence.

How this page was made

  1. Draft from memory (model judgment, step 1a): two models list candidate first translations without web access. These are leads only.
  2. Verify every row (research, step 1b): agents with web search checked each language against national library catalogues, WorldCat, digitized title pages, and published reception studies, recording the URLs; anything not confirmed is marked unverified. The result is 01b-translations-inventory.csv.
  3. Compare memory with research (deterministic code, step 1c).
  4. Locate the passage (model points, code checks, step 2): a model returns the first and last words of the matching passage; code finds those exact words in the file and cuts the translator's text out, so the passage is never the model's paraphrase.
  5. Back-translate and categorize (model judgment with a fixed JSON schema, step 3); code then checks that every quoted phrase really occurs in its text.
  6. Translate → critique → revise (model judgment, step 4).
  7. Build this page (deterministic code, step 5): all data is embedded inline so the file opens without a server.

What to distrust. “First translation” depends on what counts: abridgements, serials, and translations of stage or film versions often came earlier than a full translation of the novel, and catalogues miss small presses. Back-translations are a model's reading and can smooth over what makes a translation strange. The change categories are judgments. Rows marked unverified are leads, not facts.
