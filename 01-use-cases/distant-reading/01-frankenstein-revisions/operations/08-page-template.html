Every change between the 1818 and 1831 Frankenstein

Mary Shelley revised Frankenstein for the 1831 edition and wrote, in its new Introduction, that the changes were “principally those of style.” This page lays out every difference between the two texts, sorted into categories by a language model, with the sample checks and disagreements recorded alongside the sorting.

The point of the exercise. A computer diff found every change, with certainty: each sentence of both editions is either matched word for word or belongs to exactly one change below, and the script that built the list checks this. The models only interpreted the changes, and the list of categories they chose from was itself an interpretive decision made before any model ran.

The pipeline

Inputs: the 1818 text (Project Gutenberg #41445) and the 1831 text (#42324), both transcribed from photo-reprints of the first printings. Each operation is a file in operations/ with the same number, run in order. The tags say whether a step is fixed code, a model’s judgment, or a human decision.

  1. Normalize and align. Strip the Gutenberg boilerplate and title pages, standardize quotes and dashes, split into sections, paragraphs and sentences, and map 1818’s three volumes onto 1831’s continuous chapters. code
  2. Diff. Match sentences inside each aligned section; every run of unmatched sentences becomes one change; inside it, mark the exact words removed and added. Changes that differ only in punctuation, capitals or hyphens are marked by rule. code
  3. Choose the categories. A prompt and a JSON schema: ten categories, significance 1–5, a rationale of 40 words or fewer, a confidence level. decision
  4. Categorize. Every change that is not punctuation-only goes to a cheap model, one change per call, with the answer forced into the schema. model
  5. Check. A seeded random sample of 100 goes to a stronger model, blind; then 25 of those are read against the text. model reading
  6. Known revisions. Revisions described by scholars (and by Shelley herself) are looked up in the change list by exact phrase. code
  7. Aggregate. Counts by category, chapter, significance and confidence; agreement for the reading. code
  8. Build this page. One HTML file with the data inside it. code

Where the changes fall

Each column is a section of the 1831 edition, in reading order (with its 1818 source on hover). The bars stack the changes by the model’s primary category; the grays are surface edits. The new Introduction (2,263 words, all new) is left out so it doesn’t flatten the rest. Click a column to list its changes below.

“Words changed” for a change is the larger of the words it removed and the words it added. A rewritten passage counts in full.
