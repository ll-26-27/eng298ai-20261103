# paper/

**Writing and Dialogue Agents: Plato, Shanahan, and Grice** is a continuous 5,013-word seminar paper, rewritten from the beginning around one claim and a sequence of textual demonstrations.

- [final.html](final.html): the standalone reading and print view.
- [final.md](final.md): the same essay, followed by Works Cited and a Note on method.
- [academic-prose-audit.md](academic-prose-audit.md): the claim, evidence, paragraph sequence, and corrections.
- [pangram/README.md](pangram/README.md): before/after checks with exact input, raw responses, and HTML reports.
- [revision-record.md](revision-record.md): the draft history and source checks.

The [renderer](../notebook/scripts/render_html.py) keeps the essay, bibliography,
and method note in separate HTML containers. It supports double spacing,
italicized titles, and local system fonts without a network dependency.
