# work/

Where a run of the notebook lands. One file per step, prefixed with the step
number, so the trail reads in order:

```text
W00_brief.md                 the brief, filled in for this assignment (present)
W01_notes_<text>.md          one file per text read, whole
W01_cross-readings.md        pairs of passages in tension across texts
W01b_seminar-notes.md        yours
W02_angles.md                the brainstorm, ranked
W03_thesis.md                the claim you chose
W04_sources.md               the quote bank
W05_outline.md               the outline
W06_outline_v2.md            the edited outline, change log on top
W07_draft_v1.md              first draft
W08_judgments.md             the judges' reports and the synthesis
W08_draft_v2.md              second draft, change log on top
W09_feedback.md              your notes, verbatim
W09_draft_v3.md              third draft
```

`W10` reads all of these and writes to `../../paper/`.

Only `W00_brief.md` is here now. The rest appear as you run the steps on
your own question.
