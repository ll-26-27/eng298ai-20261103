# W09 — Your feedback

**Runner: optional user feedback; the model applies it or continues revision.** **Reads:** `work/W08_draft_v2.md`. **Writes:** `work/W09_feedback.md` (your notes, verbatim), `work/W09_draft_v3.md`.

Read the draft as its author, because you are. Your notes go in as given,
unedited: what is wrong, what you would say differently, the sentence you
want to write yourself, the claim you no longer believe. Write the paragraphs
you want to write; the model does not get to rewrite those.

Then the model applies the notes, lists any note it could not apply and why,
and makes no other change in this pass. If a note conflicts with a judge’s
change in `W08`, your instruction takes precedence.

For a delegated run with no user feedback, record “No user feedback supplied,”
carry forward the revised draft from `W08`, and continue to `W10`. If further
model revision was requested, label that pass as model revision.
