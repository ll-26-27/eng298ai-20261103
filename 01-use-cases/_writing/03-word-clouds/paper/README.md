# Paper

The outputs. Open [`index.html`](index.html).

| File | What |
|---|---|
| `index.html` | The page: both clouds inline as SVG (hover a word for its count), the Preface, the counts, Feinberg's algorithm, his caveats. Self-contained. |
| `preface-wordle.png`, `preface-wordle.svg` | The Preface cloud, as `C2` rendered it and as scalable text. |
| `preface-counts.json` | Every word `C1` kept, with its count; 123 words. |
| `preface-layout.json` | Where each word went: size, rotation, position, colour, the font and seed. Enough to redraw it elsewhere. |
| `common-room-*` | The same three files for the committee transcript. |
