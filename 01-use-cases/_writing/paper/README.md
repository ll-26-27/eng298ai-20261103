# paper/

What you publish. `W10` writes here:

- `final.md`: the paper, with `## Works Cited` and the closing section
  `## How this paper was written`, the documentation the course's AI policy
  asks for.
- `final.html`: the same, rendered by `../notebook/scripts/render_html.py`
  as a self-contained page that prints cleanly.

Nothing lands here until `W10` runs. A paper is the last file in the folder,
not the first, which is the point of the folder.
