# A Socratic classroom

**Inputs:** a question about learning, the full *Phaedrus*, selected reading
cards, an imagined Socratic facilitator, four fictional students with distinct
starting claims, and three thought experiments.

**Operations:** ask → respond → test → revise. Each participant has a
separate system prompt, retrieved knowledge and continuity memo. Four
rounds; twenty actual model-generated replies in the worked example.

**Outputs:** a [classroom HTML page](outputs/index.html), the same
[dialogue in Markdown](outputs/conversation.md), and complete run records.
Students can add their own chatbot and rerun; an additional student makes
twenty-four turns so everyone still speaks in all four rounds.

Follow definitions, counterexamples and changes of position across the four
rounds. One model performs five roles with separate prompts and memories;
the saved dialogue shows how those roles respond to the readings and one another.
