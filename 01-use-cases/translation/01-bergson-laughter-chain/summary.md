# Translation · purpose, workflow, limits

**Question:** how does translating philosophical prose force us to choose
between literal meaning, rhythm, historical usage, and readable English?

**Material:** the opening of Chapter I of Bergson’s *Le Rire*, through “grandir
et s’épanouir.” Bergson appears in Seminar 4. The original French is a pinned
Wikisource transcription of the 1938 Félix Alcan edition; the comparison is
Brereton and Rothwell’s 1911 English translation already in the context pack.

**Workflow:** establish provenance; identify lexical choices; consider context
and rhythm; draft; critique against the French; revise; compare with the actual
published excerpt; apply an editorial brief; explain four decisions. Each
stage leaves a file, and later stages receive earlier results. The published
English text is withheld from drafting and initial revision to reduce anchoring.

**Result:** a responsive bilingual HTML page, with the source and translation
aligned by segment. The saved draft and critique let readers inspect what
changed. The notebook and script share the same prompt files.

**Limits:** the glossary is interpretive, not a verified etymological resource.
The critic uses the same model as the translator. There is one published
comparison, not a survey of translations. Automated checks enforce segment
coverage and exact annotation quotations; they cannot certify a translation.
The output is a local HTML file that readers can explore in a browser.
