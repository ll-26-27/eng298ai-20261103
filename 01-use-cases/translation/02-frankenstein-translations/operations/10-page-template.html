How this page was made

  1. Fetch the texts (deterministic code, step 0): download the public-domain texts and cut Shelley's passages out of the 1818 and 1831 editions.
  2. Find the renderings (research, step 1): agents with web search looked for the plea in full texts, previews and criticism in many languages, copying each quotation from a page they fetched, with its citation and copyright status. The lead session reconciled them into 01-renderings.csv.
  3. Re-find every quote (deterministic code, step 2): a script re-reads each source (or the local public-domain file) and confirms the quotation is there; sources a script can't read are marked.
  4. Read each rendering (model judgment with a JSON schema, step 3): back-translation, the translator's word for each key word with a literal gloss and a sense from a fixed list, and notes on the connotations; code checks that each copied word is in the quote.
  5. Compare and contrast (model judgment, then edited by hand, step 4).
  6. Check the surprising claims (research, step 5): the flagged connotation claims we looked up in dictionaries.
  7. The first translations (step 6): two models draft the list from memory (6a); agents verify every row against catalogues and studies (6b); code compares the two (6c).
  8. The awakening (steps 7 to 9): a model points to the passage in each public-domain translation and code cuts it out (7); a model back-translates and categorizes the changes (8); a translate, critique, revise chain (9).
  9. Build this page (deterministic code, step 10): all data is embedded inline so the file opens without a server.

What to distrust. The connotation notes, senses, scales and back-translations are a model's readings: read the translator's words, and check any claim about a word's history in a dictionary. A dozen or two renderings can suggest a pattern, not prove one. “First translation” depends on what counts: abridgements, serials, and translations of stage or film versions often came earlier than a full translation of the novel, and catalogues miss small presses. Back-translations are a model's reading and can smooth over what makes a translation strange. The change categories are judgments. Rows marked unverified are leads, not facts.
